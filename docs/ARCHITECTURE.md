## 1. Core Principles

- **Intelligence Proposes, Policy Authorizes**: Autonomous agents generate proposals and heuristic strategies; an external deterministic policy firewall independently validates bounds, risk, and allowances before any transaction touches a ledger.
- **Proof Before Promises**: Real-time cryptographic attestations, hardware enclave verification (TEEs), and tamper-evident audit chronicles.
- **Client-Side Key Custody**: 100% browser-local credential custody in `localStorage` / WebCrypto with zero server-side secret transmission.

---

## 2. The 8-Stage Machine Economy Lifecycle

1. **01 INTENT**: User or agent initiates goal-driven objective.
2. **02 DISCOVERY**: Swarm directory matches required capabilities across registered nodes.
3. **03 TRUST & IDENTITY**: Resolution of W3C Verifiable Credentials and decentralized identifiers (DIDs).
4. **04 EVIDENCE & CONTEXT**: Cryptographic SHA-256 fingerprinting of inputs and deliverables.
5. **05 POLICY & AUTHORIZATION**: 5-point firewall evaluation against budget and scope rules.
6. **06 EXECUTION**: Sandboxed execution across local or cloud agent runtimes.
7. **07 VERIFICATION**: Proof generation, C2PA media provenance attestation, and test suite pass checks.
8. **08 SETTLEMENT & RECONCILIATION**: Multi-chain release of escrowed funds across XRPL, Algorand, Hedera, or Flare.
